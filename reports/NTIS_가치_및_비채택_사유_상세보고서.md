# 1. NTIS는 무엇인가

**NTIS** = National Science & Technology Information Service / 국가과학기술지식정보서비스

- 주관: 과학기술정보통신부
- 운영: 한국과학기술정보연구원(KISTI)
- 개설: 2008년
- 자칭: "세계 최초의 국가 R&D 정보 지식 포털"

NTIS는 한국 정부가 수행한 모든 국가연구개발(R&D)의 과제·성과·연구자·기관·장비·사업화·기술료 정보를 하나의 포털에 통합해둔 공공 데이터 인프라다. 주요 부처(NIPA, IITP, NRF, 산자부, 중기부, 과기정통부, 교육부 등)의 R&D 과제가 원칙적으로 이곳에 기록되며, 연간 R&D 예산이 30조 원을 넘는 어마어마한 규모의 세계적으로 유일한 종합 데이터셋이다.

# 2. NTIS 데이터의 가치 — 왜 팀원1의 제안이 타당한가

## 2.1 도메인 자체의 장점

- **세계적 희소성:** 대부분의 출판·특허 데이터셋은 미국(NIH, NSF), 유럽(EU FP/Horizon), 일본(JST) 등 서구 중심. **한국 과학기술 생태계를 통째로 다루는 국가 단위 R&D 데이터는 드물다.** "K-과학 정책의 디지털 기록"이라는 타이틀이 붙을 만함.
- **대규모 누적 데이터:** 2008년 개설 이후 17년간 누적된 수십만 과제, 수백만 성과(논문·특허·보고서). 추세·트렌드 분석에 충분한 규모.
- **교차 과제·성과 구조:** 하나의 과제가 여러 논문·특허·사업화·연구자·기관·부처와 연결. 그래프 구조·멀티모달 분석에 이상적.
- **정책적으로 통제된 품질:** 부처·사업단을 거쳐 수집되므로 메타데이터 일관성 측면에서 비교적 일관됨. 미국 공공 데이터 대비 포맷 통일성 높음.
- **공공 이익 측면:** 세금으로 쓰이는 R&D의 생산성·사업화·정책 효과를 분석하는 건 사회적 대의명분이 충분.

## 2.2 즉, 팀원1의 제안은 **타당한 문제 설정**이다

참고논문(Tohalino & Amancio, 2022)의 FAPESP 연구와 동일한 틀을 NTIS에 옮기면:

- "어떤 R&D 과제가 논문/특허/사업화로 이어지는가?"
- "부처·사업별로 성공을 좌우하는 요인은?"
- "연구자 이력·기관 특성·협업 네트워크가 어떻게 결과에 영향을 주는가?"

이런 질문은 단순한 "과제 분류"나 "불량 예측"보다 훨씬 사회적 의미가 크고, 국가 R&D 평가 관행에 실제로 영향을 미칠 수 있는 문제다. **점수따기용 과제가 아니라 진짜 의미의 Application Project**다.

# 3. 데이터 카탈로그 — 11개 대카테고리·세부 항목

## 3.1 과제 정보

- 주요 항목: 과제명, 과제고유번호, 상위사업·세부사업명, 주관 부처, 수행기관, 연구책임자, 연구기간(시작/종료), 연구비(정부·민간 재원), 연구목표·내용·기대효과(텍스트), 키워드, 분야 분류·적용 분야 코드(JCR/IPC/표준분류), TRL(기술성숙도)
- 도메인 가치: 과제 메타데이터가 가장 풍부. 텍스트(요약/내용) + 수치(예산/기간) + 범주(부처/분야) 혼합 → ML 특징 추출의 원재료.
- 대략적 규모: 연 6만~8만 국가 R&D 과제 등록 (누적 100만+ 과제 추정)

## 3.2 성과 정보 — 논문

- 주요 항목: 논문제목, 저자(1·교신), 학술지명, 게재연도, ISSN, 권/호/페이지, IF(Impact Factor), KCI 등급(KCI/KCI후보/비KCI), JCR 분야 백분위, DOI
- 원천적 가치: **grant productivity 예측의 명확한 라벨 소스** (FAPESP 논문과 동일 방법론 적용)
- 한계점: 논문 메타데이터부터가 자동으로 과제↔논문 매핑이 안 됨. 수동 매칭 필요.

## 3.3 성과 정보 — 특허

- 주요 항목: 출원번호·출원일·등록번호·등록일, 발명의 명칭, IPC 코드, 출원인·발명자, 출원국가, 제품 실시 여부, 변리사·평가
- 가치: 상업적 가치 잘 드러남. "출원→등록→상용" 파이프라인의 결정점·이탈율 분석 가능.

## 3.4 성과 정보 — 연구보고서

- 주요 항목: 보고서명, 요약, 목차, 부록, PDF 원문, 발행일, 수행기관
- 가치: 완성도 높은 텍스트 코퍼스. NLP 모델 학습·적용에 이상적.

## 3.5 성과 정보 — 기타

- **시설장비**: 1억 원 이상 장비 등록. 기관·지역·분야별 활용 네트워크
- **소프트웨어(SW)**: 과제에서 개발된 SW 목록, 라이선스
- **화합물**: 신약·소재 등록
- **생명자원**: 우종·세포라인·동물모델·식물모델 등
- **신품종**: 농축산 신품종 등록
- **표준**: KS, ISO·IEC 관련 R&D 서지에 등록된 표준

## 3.6 연구자 정보

- 주요 항목: 연구자ID, 소속기관·부서, 직위, 관심분야, 전공, 참여 과제 이력, 성과 누적, 교육배경
- **FAPESP 논문 변수와 직접 대응되는 구조.** PI 단위 특징 추출이 핵심.

## 3.7 수행기관 / R&D 현황

- 주요 항목: 기관명, 유형(대학/공기업/출연/연구소/중소기업/대기업), 지역, 설립일, 과제수·예산·성과 누적 통계
- 가치: 기관 prestige 변수 생산용

## 3.8 통합공고 정보

- 주요 항목: 공고명, 부처, 상위/세부사업, 일정(공고/접수/선정), 신청자격, 첨부파일, 예산 규모
- 가치: 공고 텍스트 NLP로 "동종 공고 추천·트렌드 추세·경쟁률 예측" 가능

## 3.9 사업화 정보 / 기술료

- 주요 항목: 사업화 기술명, 기술이전/라이선스 계약일, 활용 기업명, 사업화 방식(기술이전/창업/필요자가·재활용), **기술료 금액**(결정일·수령일·금액·환수형태)
- 원천적 가치: **"사업화 성공" 라벨링의 소스.** 종속변수로 활용 가능.

## 3.10 성과활용현황조사

- 과제 종료 후 과제책임자가 매년 입력하는 "성과 활용 현황" 설문 결과.
- 주요 항목: 성과종류, 활용의 발생연도, 발생 세부 설명
- 가치: "논문 개수 이상의 실제 활용 주관적 자기보고" 데이터

## 3.11 이슈·정책·기술동향

- KISTI/NTIS가 자체 정리한 트렌드 보고서, 이슈 리포트
- 가치: NLP 텍스트 코퍼스. 정책 제안·이슈 분석용.

# 4. 접근 경로 세 가지

## 4.1 (A) 웹 검색 + Excel·PDF 다운로드 — **즉시** 가능, 단 규모 제한

- ntis.go.kr 접속 → 과제·성과·연구자·기관 통합검색 → 결과를 Excel·PDF로 저장
- 장점: 로그인 없이도 대부분 접근 가능, 코드 없이 즉시 샘플 확보
- 단점: 한 번에 다운로드 가능한 row 수 제한 (보통 1,000~5,000건). 대규모 학습용 데이터셋 구축 어려움.
- 쓸만한 용도: 소규모 사례 분석, 테스트·탐색, 발표 자료용 그림

## 4.2 (B) OpenAPI — 자동화 가능, 메타데이터 접근

공공데이터포털(data.go.kr) 또는 NTIS 직접 OpenAPI 종류:

- **국가R&D 과제검색 서비스** (data.go.kr ID 15077315): 과제 메타데이터 검색
- **국가R&D 연구보고서 검색 서비스** (15102622): 보고서 메타데이터 검색
- **국가R&D 수행기관 R&D현황조회 서비스** (15138962): 기관별 R&D 통계

- 장점: 자동화, 세션 도중 재호출 가능
- 단점: 일일 호출 한도(보통 1만회), 인증키 발급에 1~3일 소요, **실제 raw 데이터의 일부만 노출**(요약·키워드 수준)
- 쓸만한 용도: 모니터링·대시보드·대량 메타데이터 수집

## 4.3 (C) R&D 데이터 신청 (마이크로데이터) — 풍부, 단 시간 소요 큼

- 공식 사이트의 "R&D데이터신청" 메뉴 → 신청서 제출 → KISTI 심사 → 승인 → SFTP 다운로드
- 제공 포맷: SQL 덤프, CSV/Excel
- 이용 조건: "연구·기획 목적"으로만 허용. 제3자 제공·상업 이용 금지. 신청서에 목적·활용범위·결과 활용 계획 명시.
- **시간 소요: 신청→승인까지 일반적으로 수일 ~ 수주.** 교수·연구실을 통한 신청이 더 빠르고 승인률도 높음.
- 자료 관련 문의: 042-869-1115 (NTIS 이용지원)

# 5. NTIS로 만들 수 있는 ML 시나리오 다섯 가지

## 5.1 시나리오 A — 과제 생산성 예측 (FAPESP 한국판)

- 라벨: 과제 종료 후 N년(예: 3년) 내 논문 ≥1편 발생 여부 (이진)
- 특징: PI 누적 논문·인용·grant 수, 기관 prestige(총 과제·예산), 협업자 수, 분야 다양성, 예산·기간, 부처·분야
- 모델: LR·LDA·QDA·SVM·RF·GBM·MLP — 강의 100% 매칭
- 평가: PR-AUC 주, ROC-AUC 보조, 부처·분야별 분해 분석
- **해결되면 국민에게 돌아갈 의미:** 세금 투입된 R&D의 선도가 "성공 가능성 높은 과제"에 집중

## 5.2 시나리오 B — 사업화 성공 예측

- 라벨: 과제코드 → 사업화 정보 테이블에 등록 여부 (이진)
- 특징: 과제 메타(분야·예산·기간·부처) + 텍스트(요약·목표) + 연구자 이력
- 모델: TF-IDF + SVM·LR / SBERT 임베딩 + LR / RF — 강의 + 응용 결합
- 서비스가 안 되는 곳: "과제→사업화" 매핑이 NTIS 내부에서 자동이 아님 → 과제코드 조인 수동 작업 필요
- **실용적 가치:** "이 과제는 사업화 가능성 78%" 같은 서비스로 부처 공무원이 그대로 쓸 수 있음

## 5.3 시나리오 C — 과제 분야 자동 분류 (다중 클래스)

- 라벨: 부처·세부사업 코드 또는 6T 분류(IT/BT/NT/ST/CT/ET) 또는 JCR 스코프 키워드
- 특징: 요약·목표·내용 텍스트
- 모델: TF-IDF + SVM 이진 클래스 시리즈, BERT/SBERT 임베딩 + LR, LDA 토픽 모델링
- 강의 매칭: 부분적. NLP가 주이고, LR/SVM/PCA 등 정형 ML은 조연.

## 5.4 시나리오 D — 키워드/토픽 시계열 트렌드 분석

- 라벨: 없음 (비지도)
- 특징: 과제 요약·보고서 텍스트 시계열(2008~2025)
- 모델: TF-IDF + LDA 토픽모델링, BERTopic, Dynamic Topic Model
- 국내 참고 사례: "AI 신약개발 R&D 동향 분석 (NTIS 5,610건 TF-IDF + LDA, 한국시스템엔지니어링학회, 2025)" 등
- 강의 매칭: 거의 없음. 분류·예측 과제가 아니라 평가 70% "insight" 항목에서 약함.

## 5.5 시나리오 E — 연구자·기관 협업 네트워크 분석 (그래프 ML)

- 라벨: 링크 예측(미래 공동연구 발생 여부) 또는 커뮤니티 멤버십 예측
- 특징: 저자 그래프(연구자 노드 → 공동 논문·과제가 엣지), GNN/Node2Vec 특징
- 강의 매칭: **강의 범위 밖**(그래프 ML 안 다룸). 추가 수강 없으면 감점 위험.

# 6. 참고논문 — Tohalino & Amancio (2022) 자세히

## 6.1 논문 정보

- **제목:** "On predicting research grants productivity via machine learning"
- **저자:** Jorge A.V. Tohalino, Diego R. Amancio (상파울루 대학교)
- **게재지:** *Journal of Informetrics*, vol. 16, issue 3, article 101260 (2022)
- **데이터:** FAPESP (브라질 상파울루 연구재단) 연구비 grant 데이터
- **분야:** Medicine, Dentistry, Veterinary Medicine 3개

## 6.2 특징 구성 (6개 그룹)

1. **pubFeat** (출판 기반): 총 논문 수, 적어도 1편 발생 grant 수, 단일 grant에서 발생한 최대 논문 수, 평균 생산성, 성공률
2. **pubCitFeat** (인용 결합): 연간 평균 인용, h-index 등
3. **grntFeat** (grant 이력): 총 grant 수, 지도 석·박·포닥 수
4. **areaFeat** (분야 다양성): 출판 계층 별 분야 수 (3단계)
5. **collabFeat** (협업): 국내·해외 협업자 수, 교신저자 수
6. **instFeat** (기관): 총 적격 소속 기관 수, 기관 장기 합계

## 6.3 결과 요약

- 분류기 5개 비교: kNN, SVM, NB, MLP, Decision Trees
- 10-fold CV + permutation test
- **최고 정확도: Veterinary Medicine 67% 수준**, Medicine·Dentistry는 51~60%
- SVM·MLP가 가장 좋은 성능, 특징 결합에 따라 소폭 개선
- **저자 결론 인용:** "predicting grants success, at least with the considered set of bibliometric features, is not a trivial task" — 예측이 쉬운 과제가 아님을 저자가 명시

## 6.4 조현건의 해석

- 67%는 "50% 랜덤 기준에서는 의미 있음"이지만 테스트로 만들기 난이도 과제에서는 어정쩡하다. "명확한 인사이트"로 보이는 결과(예: PR-AUC 0.85+)가 아님.
- NTIS로 옮긴다고 정확도가 더 높아짐은 보장 없음. 오히려 한국 특수 변수·맥락 더해야 해석이 먹힌다.

# 7. 비채택 사유 — 다섯 가지 프로젝트 조건으로 정리

아래는 "NTIS가 나쁜 데이터"라는 뜻이 아니다. **이번 텀프로젝트의 5가지 조건에 안 맞는다**는 뜻이다.

## 7.1 조건 1 — 마감일 내 데이터 확보 가능성 (Critical)

- 텀프 제안서 마감: 2026-05-10 (오늘)
- 실행 기간: 제안서→최종 보고서·발표까지 약 5주
- NTIS 마이크로데이터 신청 → 승인: 일반적으로 수일~수주
- OpenAPI 인증키: 발급에 1~3일
- **결론: 제안서 제출 시점에 "데이터셋의 크기·유형·평가지표"를 적을 수 없다.** 추상적으로만 쓰면 평가 감점 사유.

## 7.2 조건 2 — 강의 명세 부합 (Risk)

- NOVA50101 명세: "You can choose the dataset freely from **Kaggle datasets**."
- 단, 강의 구두로 "Kaggle 의무 아님" 공지가 나왔다 → NTIS도 원칙적 허용
- 하지만:
  - 제안서 "Top 3 upvoted 노트북 URL" 항목 면제 필요 → NTIS는 Kaggle 노트북 없음
  - "comparing it with the most upvoted codes" 평가 기준 → NTIS는 비교군 찾기 어려움
- **결론: "타 대회 동등 수준의 원외 데이터"로서 교수·TA 사전 승인이 필요한데, 테크니컬한 부담 크다.**

## 7.3 조건 3 — 인사이트 및 originality (평가 70%) (Risk)

- FAPESP 논문 자체가 정확도 67% 수준
- NTIS의 한국 상황이 더 나을 근거 없음 — 국가과학기술 생태계의 교차·풍부함은 장점이면서 동시에 소음 원인(부처·재원 구조, 특혜 사업)도 많음
- **한국 NTIS로 텍스트마이닝 선행연구가 이미 존재:** "AI 신약개발 R&D 동향 분석" 등 5,610건 규모 논문이 공개. 차별성 입증 시 부담 증가.
- **결론: 우리가 5주 안에 "명확한 우세 입증"을 보이기 어려움.** ablation 차별점만으로는 논문 수준에서 종속적 이미가 있음.

## 7.4 조건 4 — 강의 알고리즘 커버리지 (Risk)

- 데이터 특성이 텍스트 + 메타 수치 혼합
- LR·SVM·PCA·RF·GBM·MLP·Stacking은 사용 가능… 단 **자연스러운 CNN 활용 불가**
- L7·8 SVM·트리 등은 잘 먹으나, L13~16의 NN/CNN/PyTorch를 **자연스럽게** 들이대기 어려움
- 굳이 NLP로 빠진다면 LDA 토픽모델·BERT 동원 — 강의와의 좁은 교집합만 쓴다는 느낌
- **결론: KAMP 사출성형/CNC 수준의 "14개 알고리즘 자연 시연"을 NTIS에서 돌려주기는 힘들다.**

## 7.5 조건 5 — 팀 적용 난이도 및 리스크 (Risk)

- 4명 팀이 과제↔논문 매핑을 수동으로 짜고, 텍스트 임베딩을 일으켜 쓰고, 그래프 ML까지 가는 건 난이도 상당
- 제안서에는 그럴듯한 계획이지만, 실제 결과가 관성·잡음 같은 난도의 그림으로 그칠 리스크 큼
- **결론: 잡음 그림으로 마쳤을 때 평가 70%의 "insight from results" 항목이 제일 취약.**

# 8. NTIS를 다음에 쓰는 게 맞다 — 미래 활용 아이디어

## 8.1 졸업프로젝트·대학원 주제 (4~6개월 규모)

- **한국형 grants productivity 예측:** NTIS 마이크로데이터 정식 신청 → PI·기관·협업·분야·예산 다차원 특징 추출 → 부처에 따른 서브그룹 분석 → 67% 넘기는 설명력 높은 모델 구축
- **사업화 성공 예측 서비스:** 과제 메타 + 연구자 이력 → 등록 특허 + 기술료 데이터로 라벨 → 부처 정책 입안·자금 배분에 일도 제안

## 8.2 학회 논문 주제 (3개월 규모)

- 부처·분야별 R&D 생산성 격차 분석 (descriptive)
- 특허 발생 과제의 공통 키워드 트렌드 (LDA 동적 토픽 모델링)
- 연구자 이동 네트워크와 성공 상관관계 (graph + node features)

## 8.3 공모전·대회

- 공공데이터 대상 창업아이디어 공모전 (세종학관, 행안부, 대학상 등)
- 철저한 K-AI: 한국의 공공 R&D 투명성·결과관리 강화 제안

# 9. 한 마디 결론

> NTIS는 **좋은 데이터셋이면서 동시에 "이번 텀프에는 안 맞는" 데이터셋**이다. 5주 프로젝트 윈도우에서 계량·평가 가능한 수준으로 정리하기 어렵고, 강의 14개 알고리즘 중 CNN을 자연스럽게 쓸 수 없으며, 참고논문 정확도 67%는 "우리 모델이 더 좋다"를 입증하기에 애매한 장소이기 때문이다. 그러나 NTIS 데이터 자체는 K-과학정책의 고유 권역을 다룰 수 있는 독보적인 자원이며, **졸업프로젝트·석사논문·공모전** 등 더 긴 호흡으로 가는 그릇에서 제대로 다루는 게 올바른 선택이다.

팀원1에게는 "좋은 아이디어였으나 시기·여건상 맞지 않았다"는 프레이밍으로 전달하고, **다음 프로젝트에서 같이 하자**는 제안이 가장 공정하다.
