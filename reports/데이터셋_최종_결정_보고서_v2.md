## 0. TL;DR (3줄 요약)

1. **강의 알고리즘 전체 목록은 LR/L1·L2 정규화 → LDA/QDA → K-NN → SVM(linear/RBF) → Decision Tree → Bagging/AdaBoost/Random Forest/GBM → Stacking → PCA → MLP/Backprop/SGD/Momentum/Dropout → CNN(Conv) → PyTorch 구현까지 도합 13~14개**다.
2. **CNN(Conv)이 강의에 포함**되어 있어, **다채널 센서 시계열 구조를 가진 KAMP CNC가 1순위**로 올라간다 — 강의의 모든 토픽을 한 데이터셋으로 자연스럽게 시연 가능하기 때문이다.
3. **확정 순위: ① KAMP CNC 머신 → ② SECOM (Kaggle) → ③ KAMP 냉간단조 → ④ KAMP 사출성형. NTIS는 비채택 (부록 §B 참고).**

### 1.1 강의가 분명히 다룬 알고리즘 카탈로그 (요약)

13~14개 알고리즘으로 정리:

A. **선형·생성적 분류기:** Logistic Regression(L1/L2), LDA, QDA  
B. **거리·마진 기반:** K-NN, **SVM (linear, polynomial, RBF kernel)**  
C. **트리·앙상블:** Decision Tree, **Bagging**, **Random Forest**(implied), **AdaBoost**, **Gradient Boosting**(implied via "Bagging vs Boosting")  
D. **메타 학습:** **Stacking**  
E. **차원 축소:** **PCA**  
F. **신경망:** MLP, Backprop, SGD/Momentum/Adam, **Dropout**, ReLU/Sigmoid/Tanh  
G. **딥러닝:** **CNN (Convolution)**, **PyTorch 구현**  
H. **평가·검증:** ROC-AUC, PR-AUC, F1, 운용점 분석, Stratified k-fold CV

이게 우리가 텀프로젝트에서 "썼다"라고 보여줘야 하는 알고리즘 풀이다.

### 1.2 핵심 신규 발견: **CNN이 강의에 포함**

> v1에서는 "DL 사용 시 LR/SVM 베이스라인 의무"라는 명세만 보고 NN 정도까지만 가정했지만, lecture15\_16의 후반부(p.109 이후)에서 **Convolution / CNN / Deep Learning** 섹션이 명시적으로 다뤄진다. PyTorch 구현 흐름까지 강의에 포함되어 있다.

함의: **다채널 센서 시계열 또는 이미지·신호 구조를 가진 데이터셋이 가산점**이다. CNN을 자연스럽게 시연할 수 있기 때문.

## 4. 확정 순위와 근거

### 🥇 1순위 — KAMP CNC 머신 (확정)

**핵심 근거 4줄:**
1. **강의 13~14개 알고리즘 중 CNN까지 포함해 거의 전부 자연스럽게 적용 가능한 단 하나의 후보.** 다채널(X/Y/Z 위치·속도·가속도·스핀들 RPM·전압·전류) 센서 시계열이라 1D-CNN이 강제 없이 들어간다.
2. **공식 가이드북이 DNN 단일 모델** → 우리의 단계별 ablation(LR→LDA/QDA→SVM→Tree→Bagging→AdaBoost→GBM→Stacking→PCA→DNN→1D-CNN)으로 가이드북을 정면 비교 대상으로 둘 수 있어 **originality 차별점이 가장 명확**.
3. **Industrial AI 코스 테마와 가장 직접적으로 부합.** "산업AI를 위한 인공지능학 개론"이라는 강의 부제와 가공 공정 불량 예측이라는 응용이 1:1로 맞물림.
4. **데이터 규모(96K × 48)가 안전 영역.** 1.5K(SECOM)만큼 작지도 않고 88만(사출성형)만큼 무겁지도 않아 CNN 학습·CV·하이퍼튠을 마감 내 모두 돌릴 수 있는 유일한 KAMP 데이터.

**제안서에 적을 베이스라인:**
- KAMP 공식 가이드북(DNN 단일 모델) — 그 위에 우리의 단계별 ablation을 얹는 것이 차별점
- 텀프 명세상 "If no public code is available for the dataset, you do not need to submit baselines' URLs" → KAMP는 Kaggle 등재 아니므로 이 면제 조항 활용

**리스크와 대응:**
- 🔴 **Kaggle 등재 아님** → 텀프 PDF의 "If no public code is available… do not need to submit baselines' URLs" 조항으로 면제. 제안서 제출 시 TA에게 1줄로 사전 고지 권장.
- 🟡 **CNN 학습 시간** → 1D-CNN 정도면 Colab 무료 GPU로 충분. 데이터 96K × 48이라 큰 부담 아님.
- 🟡 **시계열 윈도우링 전처리 노력** → 사이클 단위 집계 또는 슬라이딩 윈도우 두 옵션 모두 시도 → 그 자체가 "전처리 비교" ablation 거리.

### 🥈 2순위 — SECOM (Kaggle, 백업안 1)

- **유일한 Kaggle 등재 후보** → 제안서 "Kaggle URL + Top 3 노트북" 100% 충족.
- **결측 처리(5~60%)와 PCA(591→k차원)의 효과가 가장 극적.**
- 단점: **CNN 자연 적용이 어려움**. CNN 시연이 핵심이라면 떨어지지만, "DL은 MLP까지만"으로 전략을 짜면 SECOM이 안전한 1순위 후보.
- **추천 시나리오:** 팀이 CNN 시연을 부담스러워하거나, 베이스라인 비교(Kaggle 노트북)에 무게를 두고 싶다면 SECOM으로 변경.

### 🥉 3순위 — KAMP 냉간단조 (백업안 2)

- 매우 낮은 양성비(불량 빈도 매우 낮음) → 운용점 평가가 가장 의미 있는 후보.
- 시계열 색이 강한 변수 → 1D-CNN 윈도우 분석 가능.
- XGBoost 가이드북과의 비교 명확.
- 단점: 58만 행 × 57변수로 5-fold CV에서 시간 부담. CNN까지 얹으면 Colab GPU 시간 빠듯할 수 있음.

### 4순위 — KAMP 사출성형 (백업안 3)

- 88만 행, 27변수, 사이클 단위 집계.
- 사전 표준화로 인해 **결측 처리·전처리 비교 ablation의 효과가 약함** → 차별점 한 축이 빠짐.
- CNN 자연 적용이 어려움.
- AE/SVM/DNN 가이드북이 풍부한 점은 강점이지만, 차별성 한 축이 빠진 것을 상쇄하지는 못함.

### ❌ 비채택 — NTIS (부록 §B 참고)

- 마이크로데이터 신청 절차 + Kaggle 미등재 + FAPESP 참고논문 정확도 67% → 종합 비추천 결정 (v1과 동일).
