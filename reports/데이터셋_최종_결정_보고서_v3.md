### 입력 1 — "Kaggle 데이터셋 의무가 아님" (강의 구두 공지)

| 영향 항목 | v2까지 가중치 | v3 처리 |

| Kaggle 등재 여부 | 14~15% | **0% (삭제)** |
| 베이스라인 비교군 풍부도 | 10% | **18%로 상향** — Kaggle 의무 풀리면 "Kaggle 노트북"과 "KAMP 가이드북"이 동급 평가 대상이 됨. 풍부함만 남는다. |
| 코스 명세 부합 | 15% | **15% 유지** — 단, "Kaggle URL 제출"은 무관, "DL 사용 시 LR/SVM 베이스라인 의무"만 살아있음 |

→ **SECOM의 핵심 강점이 사라진다.** Kaggle Top-3 노트북 비교는 더 이상 가산점이 아니다.

### 입력 2 — "KAMP 사출성형은 UNIST 가이드북이 있다" (사용자 강조)

KAMP 사출성형 가이드북(KAIST·UNIST·㈜이피엠솔루션즈)은:
- **AutoEncoder → SVM → DNN** 세 모델을 차례로 학습해 best를 고르는 구조
- 코스 교수(Taehwan Kim, UNIST)와 같은 학내 그룹의 작업물
- → **평가자에게 가장 친숙한 비교 대상**, 인용해도 자연스러움

이 가치는 v2에서 제대로 반영되지 못했다. v2는 "DNN 가이드북 1개"라는 KAMP CNC와 "AE/SVM/DNN 가이드북 3개"라는 KAMP 사출을 거의 동등하게 봤지만, **3개 모델 비교 vs 1개 모델은 originality 차별점에서 큰 차이**다:

> "단일 best 모델 선택"이라는 가이드북 패러다임을 정면으로 비판하려면, 그 가이드북이 **여러 모델을 시도하고도 단일 best로 귀결**되는 게 가장 좋다. KAMP 사출성형 가이드북이 정확히 그 케이스다.

## 4. 결정 트리 — 사출 vs CNC

```
Q1. 평가자(교수)에게 친숙한 학내 가이드북과의 정면 비교가 originality의 핵심이라고 본다면?
    → KAMP 사출성형 (가이드북 3모델 vs 우리 ablation)
Q2. 강의 마지막 토픽인 CNN을 자연스럽게 시연해 "강의 후반 토픽까지 따라잡았다"를 보여주는 게 우선이라면?
    → KAMP CNC (1D CNN over 다채널 시계열)

Tie-breaker (둘 다 중요해서 못 고르겠다면):
  - KAMP 사출에 CNN을 "보조" 로 끼워 넣자. 27변수를 슬라이딩 윈도우로 쌓아 1D-CNN을 추가하면 두 마리 토끼 모두 잡힌다.
  - 다만 사이클당 집계 변수라 1D-CNN의 자연성은 CNC 대비 명백히 낮음을 인정.
```

**v3 권고:** 사용자가 명시한 입력(Kaggle 의무 해제 + UNIST 가이드북 가치)을 그대로 반영하면 **KAMP 사출성형 1순위**가 정답이다. 다음 §5처럼 CNN을 "보조 ablation 한 단계"로만 끼워 넣으면 KAMP CNC의 강점도 부분적으로 흡수된다.

## 5. 1순위(KAMP 사출성형) 기반 제안서 v3 작성 가이드

기존 `제안서_사출성형.docx`를 베이스로 다음 5가지 보강:

1. **§3 차별점 재서술 — "AE/SVM/DNN 3모델 가이드북 vs 우리 단계별 ablation".**  
   가이드북은 "3개 모델 차례로 학습 → best 선택"이라는 *단일 점수* 흐름. 우리는 **어느 단계(결측/불균형 처리·차원축소·분류기 선택)가 점수를 좌우했는지**를 분리해 보여준다. 이게 originality의 1차 차별점.
2. **§4 (1) 단계: 결측 처리 비교의 비중을 줄이고 클래스 불균형 처리(가중치 vs SMOTE) 비교에 시간 배분.**  
   사전 표준화 데이터의 약점을 우회. 이미 기존 제안서에 명시되어 있으니 그대로 유지.
3. **§4 (2)–(3) 단계 유지:** 선형·생성적 베이스라인(LR/LDA/QDA/SVM linear·RBF) → PCA(80/90/95/99% 분산 보존) + 트리 중요도 + 분산 임계값 비교.
4. **§4 (4) 단계 확장 — "앙상블·신경망·스태킹·CNN 보조".**  
   - Random Forest, Gradient Boosting, 가이드북 DNN 재현, **+ 1D-CNN(슬라이딩 윈도우 입력) 보조 단계**, Stacking 메타 학습기.  
   - CNN은 "주력 모델"이 아닌 "강의 후반 토픽 시연" 위치로 명시.
5. **베이스라인 URL 항목:** "KAMP 공식 가이드북 (KAIST·UNIST·㈜이피엠솔루션즈, AE/SVM/DNN 3모델 비교). Kaggle 미등재 데이터셋이며 강의에서 Kaggle 의무 해제가 공지된 점을 적용."로 1줄 명시.

→ 이렇게 하면 **§3 originality(AE/SVM/DNN 가이드북 비교) + §4 (4) CNN 보조**로 "사출성형의 약점(CNN 부자연)"을 보강하면서 **사출성형의 강점(가이드북 3모델 비교)**을 그대로 살린다.
